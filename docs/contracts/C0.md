# C0 v1 — A/B integration

Baseline: `b4772099c5591e8a83152a767ecb1004972b266b` (Studio 3.3).

`clipper.contracts` implements envelopes, validation, stable word lineage and
legacy adapters. `AnalysisHost` injects snapshot, submit_changes,
get_words_page and run_stage; an A router may be mounted without global state.
No model result is fabricated by these adapters.

| Boundary | Producer | Required payload semantics |
|---|---|---|
| MediaContext | B | Content identity, display dimensions, rotation, SAR, audio track, color interpretation |
| TranscriptSnapshot | A | transcript_id, revision, words; immutable word_id/origin_word_ids |
| CandidateSet | A | candidates with source spans and evidence IDs |
| SceneAnalysis | A | source spans; boxes with explicit coordinate space/dimensions |
| CaptionPlan | A | variant_id, timeline_revision, phrases bound to source-word lineage |
| AssetProposalSet | A | source span, asset identity, relevance and provenance |
| EditTimeline | B | clip/variant/revision, rational fps, exclusive frame endpoints |
| RenderManifest | B | dependency fingerprint, variant, timeline revision, actual assets, QC |

Envelope fields: schema_version=1, producer_version, kind, source_id,
input_fingerprint, state (ready/empty/blocked/error/stale), payload.
Times: half-open source seconds. Output frames: end exclusive. IDs survive text
correction and style changes; split/merge tokens keep origin_word_ids.

Ownership: A owns illustration_catalog.py and caption_checks.py after this
mechanical extraction. B owns illustration_schedule.py and the illustrations.py
facade. Existing prepare/propose/attach/credits imports remain valid. The facade
passes its proposer explicitly, preserving the legacy test injection point.

Production API uses expected_revision + operation_id with atomic compare/write.
GET snapshots are deep copies. Word pagination requires the same revision; stale
cursors return conflict. Source corrections target word identities, not spelling.
Variants share source utterances but have independent settings and render keys.

Changes to this contract require both streams' contract tests to pass. A should
merge this extraction before modifying these newly owned files; do not replace
an integrated tree with an older installation ZIP.
