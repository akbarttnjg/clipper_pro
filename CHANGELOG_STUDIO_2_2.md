# Studio 2.2.0 — 24 September 2026

- Lima preset tipografi bertingkat dengan pop, geser empat arah, blur→tajam,
  variasi ukuran, warna, regular/bold/italic, dan tiga intensitas gerak.
- Galeri preview MP4 lokal; pilih pada clip aktif atau terapkan ke clip terpilih.
- Rencana motion bersama untuk ASS, keyframe CapCut, dan kurva Fusion.
- Gabungan token mata uang, pecahan desimal, dan satuan tanpa mengubah transkrip.
- Deteksi papan berbasis proyeksi melengkapi kontur; ruang teks terpisah pada
  komposisi materi/pembicara bila geometri memungkinkan; tambahan headroom.
- Video tanpa teks dalam paket editor mempertahankan komposisi dan zoom.
  ASS master, SRT, font, WAV, dan rencana edit asli disertakan.
- Cache video tanpa teks memeriksa rencana, sumber dan audio; relink paket
  memeriksa lokasi media yang baru. Audio ditulis melalui file sementara.
- Koreksi penanganan selisih pembulatan durasi audio saat ekspor CapCut.
- Nama render baru memakai -v22; hasil lama tidak ditimpa. Hasil lama/dirty
  ditandai di UI. Tombol unduh ASS tersedia untuk render baru.
- Tidak menambah model AI, API berbayar, atau dependensi runtime.

CapCut: blur/fade teks native belum dipetakan. Resolve/CapCut: pengujian impor
langsung di Windows masih diperlukan. MP4/ASS berisi animasi penuh.
